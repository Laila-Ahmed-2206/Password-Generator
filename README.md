# Password Generator
A modern and responsive password generator built using HTML, CSS, and JavaScript.

## Features
- Generate secure random passwords
- Adjustable password length
- Include/exclude:
  - Uppercase letters
  - Lowercase letters
  - Numbers
  - Symbols
- Copy password to clipboard
- Password strength indicator
- Responsive design

## Technologies Used
- HTML5
- CSS3
- JavaScript (ES6)
